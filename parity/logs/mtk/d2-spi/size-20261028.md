# D2 benchmark buffer memory comparison — 28 October 2026

Build baseline: `main` at `8ee7b6f` with `s_latencies[1000]` in internal BSS. After change: the same source baseline with `EXT_RAM_BSS_ATTR` on that 4,000-byte array. Both images built with the pinned ESP-IDF v6.1 development commit and course µT-Kernel port. ESP-IDF's `size` report gave:

| Memory | Before (bytes) | After (bytes) | Change |
|---|---:|---:|---:|
| DIRAM used | 334,511 | 330,511 | −4,000 |
| External RAM BSS | 130,736 | 134,736 | +4,000 |

The post-change firmware built and its GPIO12↔GPIO13 loopback regression passed [22/22 functional checks](spi-20261028-after-powercycle.log), [6/6 connected fault checks](fault-connected-20261028-corrected-label.log) and an [8,000-transfer benchmark](bench-20261028-rejoined/RESULTS.md) with zero HAL errors and byte mismatches. This comparison covers static placement; it does not claim a full-load application memory result.
