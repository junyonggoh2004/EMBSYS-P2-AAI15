The `people-counter` window is a model-specific exception to the 16-binding configuration limit: **one sonar binding fills 31 time slots**. The sine and comfort models keep their original input shapes. The normal four-sensor profile is 2 Hz per sonar; the isolated people-counter profile samples Sonar A every 70 ms and configures B's remote alias for the same period. The source model was trained around 50 ms per sample. Its B-side output is experimental until real readings and labelled crossing trials are captured.

The [24 Nov live test record](PEOPLE_COUNTER_LIVE_TEST_20261124.md) captures the verified A→B model result, the MQTT burst timing fix, and the restored A→B→C display path.
