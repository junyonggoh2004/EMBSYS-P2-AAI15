The D6 demo uses `sine-float`, `sine-int8`, `comfort-summer`, and `people-counter`; the bundled autoencoder remains outside this use case. See [the use case](SONAR_ONLY_USECASE.md) for the crossing rules and the [model-by-model ML commands](../../ML_commands.md) for live configuration and switching. Status is based on code and recorded tests; a build or host test is not a physical doorway validation.
