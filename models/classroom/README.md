# Classroom model assets

`comfort_summer.tflite` is the published FP32 checkpoint from jbonett's Apache-2.0 thermal comfort project. Its input is `[temperature_c, humidity_pct]`, shape `[1,2]`, and its output is 100 class scores, shape `[1,100]`. The original firmware uses the winning class index as the comfort score. The file is 5,960 bytes with SHA-256 `41f80cb290e572fde7d7010fa93fed0659339c0eb38692957b38ab40e2bfdd31`. [Pinned source](https://github.com/jbonett/thermal-comfort-tflite/tree/d146711ee926a0a83cedf555b7604472efc4ca1f) · [License](LICENSE)

**`people_counter_raw_int8.tflite`** is the 10,736-byte Edge Impulse export from Jun Yong's clone of Dmitry's public `people_counter_raw` project (18808). Jun Yong reran training on the copied data and retained the source model's architecture. This checkpoint has newly trained weights. Its INT8 input has shape `[1,31]` and its INT8 output has shape `[1,3]`. It expects one preprocessed ultrasonic window and reports scores in the source project's `in`, `none`, `out` order. SHA-256 `89081fc1d437747dee4a687266184ba7f42dd2ded86088303e0afa0002dd15e4`. [Public project](https://studio.edgeimpulse.com/public/18808/latest) · [License and attribution](PEOPLE_COUNTER_LICENSE) · [Run guide](../../docs/embedded-ml/RUNNING.md#switch-between-the-classroom-demo-models)
