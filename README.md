# D1 — Port configpico2wedge to ESP32-S3

Branch: `s3-port`. The Pico 2 W build is kept only as the reference that ESP32-S3 parity is measured against.

Pico reference build and ESP32-S3 Arduino setup instructions are in [SETUP.md](SETUP.md). The framework's configuration syntax and command reference are in [project_v3/README.md](project_v3/README.md).

The ESP32-S3 port uses Arduino IDE and the Arduino-ESP32 core. Shared configuration, scheduling, sensor, rule, output, MQTT and inference logic should call a portable HAL instead of Pico SDK or Arduino APIs directly. The Pico SDK implementation remains the reference. Direct ESP-IDF APIs may be used underneath Arduino only where an Arduino API is insufficient; each exception must be documented and tested. The exact Arduino-ESP32 core version and board settings are still to be confirmed and pinned in `SETUP.md`.
